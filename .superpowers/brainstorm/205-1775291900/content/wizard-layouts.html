Onboarding Wizard Layout Options

Two layout approaches for both the Platform Admin wizard (/platform/tenants/onboard) and the Tenant Setup wizard (/setup)

A

Vertical Stepper (Left Sidebar)

Steps listed vertically on the left, form content on the right. Steps show completion status with checkmarks. Current step highlighted. Common in enterprise SaaS onboarding (Stripe, Salesforce).

Considerations

A — Vertical Stepper

  • Better for 6-step tenant setup wizard (steps always visible)
  • Step names can be longer and more descriptive
  • Scales well — can show sub-steps or progress within steps
  • Matches enterprise finance software conventions

B — Horizontal Stepper

  • Cleaner for the 4-step platform admin wizard (fewer steps)
  • Full-width content area gives more room for forms
  • Simpler visual — less UI chrome
  • Can feel cramped with 6+ steps (labels truncate)

Recommendation: Use A (Vertical Stepper) for both wizards. The 6-step tenant setup wizard really needs the vertical space, and keeping both wizards consistent makes the codebase simpler (shared WizardLayout component).
